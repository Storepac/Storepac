## Sobre os repositórios privados

A maior parte do que construo roda em produção para operações reais — com dados
de clientes, integrações de marketplace e regras fiscais. Por isso o código fica
privado.

O que dá para mostrar está aqui: o problema que cada produto resolve, a decisão
de produto por trás dele e o link para o que está no ar. Quem quiser entrar no
detalhe de arquitetura e decisão encontra os estudos de caso escritos em
[**techforweb-cases**](https://github.com/Storepac/techforweb-cases).
